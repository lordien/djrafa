À propos

Je suis Rafa, DJ sur le serveur. Je mixe pour les établissements, les événements et les groupes qui veulent une vraie ambiance, sans temps mort.

Mon approche est simple : écouter ce que vous voulez, préparer un set cohérent, puis lire la salle pendant la soirée pour ajuster le rythme.

Je suis ponctuel, je viens avec mon propre matériel et je reste disponible avant l'événement pour caler les détails avec vous.
